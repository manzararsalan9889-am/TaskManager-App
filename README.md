# TaskManager App

A full-stack task management app to create, update and track daily tasks, with user login.

## Stack
- Frontend: Ionic + React (TypeScript)
- Backend: .NET Core (ASP.NET Core Web API)
- Database: MySQL
- Tools: Postman, Git/GitHub, VS Code

## Features
- User registration and login (JWT authentication)
- Create, edit and delete tasks
- Mark tasks as complete
- Change password

## How to run
1. Backend: update the connection string in `TaskManager.Api/appsettings.json` with your own MySQL user and password, then run `dotnet run` from the TaskManager.Api folder.
2. Frontend: from the `Frontend/task-manager` folder run `npm install`, then `npm start`.
3. API: test the endpoints in Postman.
